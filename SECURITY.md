# Security

This repository publishes a data artifact (a controlled vocabulary), its
documentation, and small Python tooling that validates and regenerates that
artifact. It contains no credentials, tokens, or secrets, and the pipeline
is designed to run read-only checks on untrusted inputs.

## Reporting

- For ordinary bugs, documentation issues, or curation questions, open a
  GitHub issue on this repository.
- For anything you consider security-sensitive, use GitHub's private
  vulnerability reporting on this repository so the maintainers can respond
  before details are public.

Please do not include real credentials or personal data in any report.
